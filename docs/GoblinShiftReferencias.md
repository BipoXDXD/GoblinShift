## 2. Documentação oficial e especificações

Fontes oficiais agrupadas pelos componentes da stack e pelos contratos que a API utiliza. **O código usa versões fixadas:** URLs `/latest`, `/stable` ou `/current` servem para consulta, não definem a versão instalada. As regras do [plano](GoblinShiftPlan.md) são decisões de arquitetura, não garantias das bibliotecas.
