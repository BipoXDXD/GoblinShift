# ADR 010. Python 3.14

- **Estado:** aceito
- **Plano:** [1.3](../GoblinShiftPlan.md#s1-3), [2.1](../GoblinShiftPlan.md#s2-1), [3.10](../GoblinShiftPlan.md#s3-10)
- **Referências:** [D01](../GoblinShiftReferencias.md#d-1)

## Contexto

Em outubro de 2026, a 3.13 está em fase só de correções de segurança, a 3.14 recebe correções de bugs e a 3.15 acabou de sair. As regras Unicode do CSV Janitor (como a regra de caixa) seguem a versão do Python fixada, sem depender do locale do servidor ([1.3](../GoblinShiftPlan.md#s1-3)).

## Decisão

O backend usa Python 3.14. A versão é escolha deliberada e é feita agora porque as regras Unicode do CSV Janitor seguem a versão fixada. A migração para a 3.15 fica para quando o ecossistema (Pillow, psycopg, pydantic-core) estiver maduro. As versões exatas das dependências ficam nos lockfiles e nas imagens, e o Starlette deve ser o compatível com o FastAPI.

## Alternativas descartadas

| Alternativa          | Motivo                           |
|----------------------|----------------------------------|
| 3.13                 | Só recebe correções de segurança |
| 3.15 (recém-lançada) | Ecossistema ainda não maduro     |

## Consequências

- O plano registra que a stack ainda não foi testada como conjunto; a fatia 0 é a primeira em que ela roda no pipeline e na VPS.
- Trocar de versão do Python depois muda a base das regras Unicode do CSV Janitor, então a migração para a 3.15 é uma decisão deliberada, registrada num ADR novo ([3.9](../GoblinShiftPlan.md#s3-9): toda decisão grande vira um ADR).

## Como verificar

- `pyproject.toml` tem `requires-python = ">=3.14"` e `target-version = "py314"` no Ruff; `.python-version` contém `3.14.9`, a mesma versão das imagens base.
- `docker/app.Dockerfile` usa imagens base `python:3.14.x` nos dois estágios (hoje `python:3.14.9-slim-trixie`).
- O CI e o workflow de restauração instalam o Python de `.python-version` com `actions/setup-python` antes de `uv sync --locked`. O catálogo de downloads embutido no uv ainda não inclui o patch 3.14.9; a instalação explícita evita depender dessa defasagem.
- Na fatia 2, os testes do CSV Janitor que dependem de Unicode (regras `lower` e `upper` de `case_rules`, como ß → SS) passam na versão fixada.
